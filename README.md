# Neelakandan N — Personal Portfolio

A clean, responsive, single-page portfolio website showcasing academic research in mathematics, data analytics, and Android systems engineering. Built with semantic HTML5, modern vanilla CSS (using CSS custom properties), and lightweight JavaScript.

## Features

- **Interactive Fuzzy Membership Visualizer:** An interactive SVG demo modeling $\mu(x)$ triangular membership functions live via drag interactions and idle oscillations.
- **Light / Dark Theme Toggle:** Fully custom light and dark color schemes with auto-detection for system preferences (`prefers-color-scheme`) and persistence across sessions via `localStorage`.
- **Semantic & Minimalist Markup:** Built using standard semantic elements (`<nav>`, `<main>`, `<section>`, `<time>`, `<dl>`, `<output>`) without external CSS frameworks or heavy JavaScript dependencies.
- **Scroll Reveal Animations:** Powered by native `IntersectionObserver` for smooth, performant component entrance effects.
- **Accessibility & Motion Consideration:** Respects `prefers-reduced-motion` settings and supports visible focus states.

## Tech Stack

- **Markup:** HTML5
- **Styling:** Vanilla CSS (CSS Variables, Flexbox, CSS Grid)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (*Fraunces*, *IBM Plex Sans*, *IBM Plex Mono*)
